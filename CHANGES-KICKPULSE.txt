KickPulse update 7 (Nov 2026) - fix "Could not load live scores / HTTP 400" on MLS pages
- api/scores.js: when ESPN answers 400 for a league, it now retries simpler versions (without limit, day by day, ESPN default day); a final 400 = "no matches" instead of an error.
- assets/app.e2b39741.v4.min.js (new name so browsers drop the old file): trusts the server answer, and an ESPN 400/404 on the direct fallback shows "no matches" instead of an error. All pages point to v4.

KickPulse update 8 (Nov 2026) - friendly "no matches" box instead of "Could not load live scores / HTTP 400"
- assets/app.e2b39741.v5.min.js (new name so browsers drop the old file; all pages point to it).
- When a league has no matches (or ESPN answers 400/404), the page now shows a blinking box: "No MLS matches today ... read our previous MLS match previews and articles on Pitchside Notes", with the matching articles (read live from kickpulse-final.vercel.app/articles.json) and the last 3 finished results of that league.
- Articles are matched to the league by words in the title, description, URL (or optional "league", "tags", "category", "keywords" fields in articles.json). Keywords per league are in the KK list at the top of the JS file.
- If no article matches the league, the latest 3 Pitchside Notes articles are shown instead.
- Technical text like "HTTP 400" is never shown to visitors. Only a real offline browser shows "You seem to be offline".

KickPulse update 9 (Nov 2026) - ESPN live scores work again + Pitchside slider
- assets/app.e2b39741.v7.min.js (all pages now point to it; v5 was still in use, v6 was never linked):
  * League pages (MLS, Premier League ...) ask ESPN straight from the visitor's browser FIRST (the way that always worked),
    and use /api/scores only as a backup. An empty answer from the server is no longer trusted as "no matches".
  * Home / all-leagues pages: one /api/scores call; if the server returns nothing at all, the browser asks ESPN itself.
  * Refresh button and midnight rollover from v6 included. Interface, design and text are unchanged.
- assets/pn.v2.js (pages point to it): top bar and the Pitchside box now slide through ALL articles from the blog's articles.json
  (arrows, dots, swipe, auto-slide, pauses on hover/touch). If the blog is unreachable the built-in text stays.
